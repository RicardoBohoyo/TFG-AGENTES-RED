\## Descripción

Este repositorio contiene el código fuente y las pruebas de concepto desarrolladas para el TFG. El proyecto se centra en la transición del modelo tradicional de operaciones de red (NetOps) hacia la automatización inteligente (AIOps). 



Se utiliza la arquitectura de grafos de estado de \*\*LangGraph\*\* para implementar agentes autónomos (IA Agéntica) capaces de razonar, utilizar herramientas externas y realizar tareas de monitorización, diagnóstico y triaje de incidencias de red de forma determinista y segura.
